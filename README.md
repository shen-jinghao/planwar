# 飞机大战

这是一个使用 C++ 和 EasyX 实现的 2D 飞机射击小游戏。项目包含主菜单、背景切换、存档管理、暂停菜单、道具掉落、Boss 战、爆炸动画、音效和背景音乐等功能。

## 项目内容

- `main.cpp`：程序入口和主循环。
- `Game.*`：游戏全局数据、存档读写、敌人生成、击杀结算和通用绘制。
- `States.*`：主菜单、存档页、暂停、游戏结束、死亡演出和局内游玩状态。
- `Entities.*`：玩家、敌机、Boss、子弹、道具和动画效果。
- `Resources.*`：图片和音频资源加载与缓存。
- `RenderUtil.*`：图片绘制、背景缩放、中文文本绘制等渲染工具。
- `image/`、`music/`：游戏图片和音频资源。

## 玩法简介

玩家控制飞机躲避敌机和敌方子弹，并自动发射子弹攻击敌人。击毁敌机会获得分数，并有概率掉落生命、炸弹或火力强化道具。击毁数量达到指定条件后会出现 Boss，Boss 会释放更密集的弹幕和特殊子弹。

## 操作方式

- `WASD` 或方向键：移动飞机。
- 鼠标左键拖动：移动飞机。
- `P`：暂停或继续游戏。
- `B`、鼠标右键或右上角炸弹按钮：使用炸弹。
- 主菜单可选择不同背景，也可以进入存档读取。
- 局内或暂停菜单可进入存档管理。

## 编译方式

项目使用 MinGW g++ 和 EasyX for MinGW。可以直接运行项目根目录下的：

```bat
bulid.bat
```

也可以手动执行其中的编译命令，生成 `PlaneWar.exe`。

如果编译时提示无法覆盖 `PlaneWar.exe`，请先关闭正在运行的游戏窗口。
